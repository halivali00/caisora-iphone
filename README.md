# CAISORA iPhone — Phase 1 (PWA)

Prototype web installable sur l'écran d'accueil iPhone via Safari. Fonctionnalités actuelles : ajout/suppression de produits, référence, prix, couleur, taille, quantité, totaux et export JSON. Le stockage est local au navigateur.

## Utilisation iPhone
1. Publier le contenu de ce dossier sur un hébergement statique HTTPS.
2. Ouvrir l'adresse publiée dans Safari.
3. Toucher Partager → Sur l'écran d'accueil.
4. Ouvrir CAISORA depuis l'icône.

## Limites importantes
Ce ZIP est le code source, pas une URL déjà publiée ni une application App Store. Le service worker/offline exige HTTPS. Les données peuvent être perdues si les données du site sont supprimées : exportez des sauvegardes. Aucune synchronisation Windows, caisse complète, gestion clients/fournisseurs, authentification ou test commercial n'est incluse. Aucune base Windows n'est fournie ou modifiée.
